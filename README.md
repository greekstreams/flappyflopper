# Flappy Flopper 🏀🐦‍⬛

Welcome to Flappy Flopper, where the art of drawing contact meets the simple (yet infuriating) mechanics of classic tap-to-fly games! Guide Sasha Vezenkov, master of the strategic stumble, through a gauntlet of reaching hands. Every tap is a tactical flop, a necessary maneuver to gain altitude and avoid the defense.

This project is a fun side-project and a humorous tribute to both Vezenkov's unique playing style and the iconic Flappy Bird game.

**➡️ [Play Flappy Flopper Live!]([https://greekstreams.github.io/flappyflopper/])** ⬅️ 

---

## Features

*   Classic tap-to-fly gameplay mechanic.
*   Unique basketball foul-drawing theme starring Sasha Vezenkov.
*   Simple, addictive, and challenging gameplay.
*   High score tracking using browser Local Storage.
*   Built purely with vanilla HTML, CSS, and JavaScript.
*   Responsive design for different screen sizes (including mobile).
*   Includes About and Privacy Policy pages.

## Technology Stack

*   **HTML5:** For structuring the web pages.
*   **CSS3:** For styling the game elements, layout, and responsiveness.
*   **JavaScript (Vanilla):** For game logic, physics, controls, and scoring.
*   **Google Fonts:** Using the 'Poppins' font for typography.
*   **Font Awesome:** For icons (used minimally, primarily on the About page).
